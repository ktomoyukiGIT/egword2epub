# 見本

使い方の説明（[docs/guide.md](../docs/guide.md)）で使っている見本です。

| ファイル | 中身 |
|---|---|
| `neko.txt` | egword から書き出したテキストの形。夏目漱石『吾輩は猫である』の冒頭に、説明のための脚注を一つ足したもの |
| `neko-done.txt` | `neko.txt` に、説明のとおりに注記を書き足したもの |
| `neko.toml` | 設定ファイルの見本 |
| `cover.jpg`・`ch01.jpg` | 表紙と章扉の画像（見本のために作ったもの） |

本文は[青空文庫](https://www.aozora.gr.jp/cards/000148/card789.html)のテキストを元にしています（著作権の切れた作品です）。
