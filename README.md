# Egword2EPUB

egword の書き出しテキストから、縦書きの EPUB3 を作るアプリです。

[egword Universal 2](https://monokakido.jp/ja/mac)（物書堂）は、macOS 用の日本語ワープロです。さまざまな書式が使え、書いた原稿はそのまま PDF にできます。青空文庫形式（Shift_JIS）のテキストを開くことも、簡易的な青空文庫形式のテキストとして書き出すこともできます。

このアプリは、egword から書き出したテキストに章の区切りなどの注記を少し書き足して、縦書きの EPUB3 にするものです。

- egword が書き出すルビと傍点（ルビの形で書き出されるもの）は、そのまま生きます。ルビによっては、範囲を「｜」で示す必要があります。
- 脚注と文末注は、書き出されたままの形から自動で見分け、本文と相互にリンクします。注の番号は自動で縦中横になります。
- 改ページとセクション区切りは、そのまま頁の区切りになります。
- 図版は、注記を書き足すと入ります。

書き足す注記は、青空文庫の形式です（一部、このアプリで足したものがあります）。egword を使っていなくても、同じ書き方のテキスト（UTF-8 または Shift_JIS）であれば、一から書いたものでも編集して変換できます。

できること：

- 縦書き（既定）と横書き
- ルビ、傍点（各種）、傍線（各種）、縦中横、太字、斜体、文字の大小
- 字下げ・地付き・字上げなどの範囲注記と行注記
- 脚注（対応アプリでは小窓で表示）と文末注。本文と注を相互にリンク
- 表紙、章扉、図版と説明文
- 目次（nav）の自動生成。本文中の目次頁の自動生成、または手作りの目次頁へのリンク付け
- 書き損じを警告の一覧で示す（変換は止めない）

原稿を書き、注記を入れ、縦書きのプレビューで確かめ、EPUB に書き出すまでを、一つの画面で行います。

![注記を入れて、縦書きのプレビューで確かめる](docs/media/02-annotate.webp)

**使い方は [docs/guide.md](docs/guide.md) に、動画つきでまとめてあります。** 見本のテキストと画像（[`sample/`](sample/)）で、すぐに試せます。

## 使い方は三通り

| 形 | 動く場所 | 入れるもの |
|---|---|---|
| [ブラウザ版](https://ktomoyukigit.github.io/egword2epub/) | パソコンやスマホ（Android など）のブラウザ | なし。開くだけ |
| デスクトップのアプリ | Mac・Windows・Linux | 組み立てに Rust |
| コマンド | どこでも | 組み立てに Rust |

どれも中身は同じで、同じテキストからは同じ EPUB ができます。

### ブラウザ版

上の表のリンクを開くだけで使えます。テキストや画像はどこにも送られず、変換はブラウザの中だけで行います。

- パソコンの Chrome・Edge では、開いたテキストにそのまま上書き保存でき、画像フォルダもフォルダごと選べます。
- Safari やスマホなどでは、画像はまとめて選び、保存と EPUB はダウンロードになります。設定ファイルは、その中で指定した CSS といっしょに選びます。書きかけのテキストはブラウザに残しておき、開き直したときに戻せます。

### Mac のアプリ

アプリは自分の Mac で組み立てます（初めての一回だけ手間がかかります）。

1. このページの緑の「Code」→「Download ZIP」で中身を落とし、展開します。
2. Rust を入れます。ターミナルで次の一行を実行し、聞かれたら Enter を押します。終わったら、ターミナルを一度閉じて開き直します。

   ```
   curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
   ```

   Xcode（またはコマンドラインツール）も要ります。入っていなければ `xcode-select --install` で入ります。

3. 展開したフォルダに移って、組み立てます。

   ```
   cd （展開したフォルダ）
   ./build_mac.sh
   ```

   初めては 5〜15 分ほどかかります。`build/Egword2EPUB.app` ができるので、「アプリケーション」フォルダに移して使ってください。自分の Mac で組み立てたアプリなので、開発元の確認の画面は出ません。

### Windows のアプリ

Windows 10・11 で組み立てられます。

1. このページの緑の「Code」→「Download ZIP」で中身を落とし、展開します。
2. [Microsoft C++ Build Tools](https://visualstudio.microsoft.com/ja/visual-cpp-build-tools/) を入れます。インストーラーで「**C++ によるデスクトップ開発**」（Desktop development with C++）に印を付けて入れてください。
3. Rust を入れます。[rustup のページ](https://www.rust-lang.org/ja/tools/install)から `rustup-init.exe` を落として実行し、聞かれたら Enter を押します（既定のまま入れます）。
4. 展開したフォルダの `build_windows.bat` をダブルクリックします。

   初めては 5〜15 分ほどかかります。`build\Egword2EPUB.exe` ができるので、好きな場所に置いて、ダブルクリックで起動します。テキストの「プログラムから開く」で選べば、そのテキストを開いて起動します。

画面の表示には WebView2 を使います。Windows 10・11 には初めから入っています。入っていないと言われたときは、[WebView2 Runtime](https://developer.microsoft.com/ja-jp/microsoft-edge/webview2/) の「Evergreen Bootstrapper」を入れてください。

Rust を前から入れていた場合は、`rustup default stable-msvc` で MSVC 用の Rust にしてから組み立ててください。

### Linux のアプリ

1. 組み立てに要る部品を入れます。Debian・Ubuntu では次のとおりです（ほかの配布形態は [Tauri の準備](https://v2.tauri.app/start/prerequisites/#linux)を参照）。

   ```
   sudo apt update
   sudo apt install libwebkit2gtk-4.1-dev build-essential curl wget file libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev
   ```

   Fedora では次のとおりです。

   ```
   sudo dnf install webkit2gtk4.1-devel openssl-devel curl wget file libappindicator-gtk3-devel librsvg2-devel libxdo-devel
   sudo dnf group install "c-development"
   ```

2. Rust を入れます。終わったら、ターミナルを一度閉じて開き直します。

   ```
   curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
   ```

3. 中身を落として展開したフォルダ（または `git clone https://github.com/ktomoyukigit/egword2epub.git`）に移って、組み立てます。

   ```
   cd （展開したフォルダ）
   ./build_linux.sh
   ```

   初めては 5〜15 分ほどかかります。`build/Egword2EPUB` ができ、アプリのメニューにも「Egword2EPUB」が加わります（`~/.local/bin/egword2epub` に置き、管理者の権限は使いません）。ターミナルからは `egword2epub 本文.txt` のように、テキストを指定して起動することもできます。

### コマンド

```
cargo run --release -p egword2epub-rs -- 本文.txt 画像フォルダ 出力.epub --config 設定.toml
```

`--css 体裁.css` で CSS を指定することもできます。

## 画面

窓は四つの欄に分かれています。

- **左：注記の一覧**　押すと、カーソルの位置に注記が入ります。文字を選んでから押すと、その文字に付けます（ルビ・傍点・太字・見出しなど）。行に付けるもの（字下げ・地付きなど）は、選んだ行すべてに付きます。章扉と図は、画像フォルダの画像から選びます。
- **中：エディタ**　左に行番号、頁の始まりに区切り線と頁の番号が出ます。改ページ記号は「改頁」の印で見えます。注記は青、ルビは緑、注の参照は橙。
- **右：縦書きのプレビュー**　カーソルのある頁を表示します。書く手を止めて少したつと作り直します。注の番号を押すと注の頁へ移ります。‹ › で頁を送れます。
- **下：問題の一覧**　変換したときの警告です。行を押すと、その場所へ移ります。

上の欄で、画像フォルダと設定ファイルを選びます。デスクトップのアプリでは、テキストと同じフォルダの画像を最初から使い、選んだものはテキストごとに覚えておきます。前に開いていたテキストは、起動したときに開き直します。

設定ファイルは「編集…」（なければ「新規…」）で、窓の中で直せます。「書誌」「組版と注」「奥付」のタブで欄を埋め、「テキスト」のタブでは設定ファイルをそのまま直せます。欄を変えずに保存したときはコメントも残り、欄を変えて保存するとファイルは書き直されます（コメントは消えます）。「確かめる」で、書き損じ（発行日の形・作者の名前・CSS が見つかるか・注の書式など）を調べます。

| 操作 | キー（Windows・Linux は ⌘ の代わりに Ctrl） |
|---|---|
| 開く・保存・別名で保存 | ⌘O・⌘S・⇧⌘S |
| 探す・置き換え | ⌘F（正規表現も使える） |
| 調べる（問題の一覧を作り直す） | ⌘K |
| EPUB を書き出す | ⇧⌘E |
| 文字を大きく・小さく | ⌘+・⌘- |
| ルビ | ⌘R |

保存するときは、開いたときの文字コード（Shift_JIS か UTF-8）と改行の形を保ちます。Shift_JIS で書けない字が入ったときは、UTF-8 で保存してよいか尋ねます。EPUB を書き出すときは、大きな画像（長い辺 2000px を超える JPEG・PNG。表紙は 2560px）を縮小します。

## 作業の流れ（egword の場合）

1. egword で原稿を書き、PDF を作る。
2. 原稿をテキストに書き出す。ルビは `漢字《かんじ》`、改ページは改ページ記号として書き出されます。脚注と文末注の本文は、セクションの終わりに並びます。
3. 書き出したテキストをこのアプリで開き、章の区切り（`［＃章扉（ch01.jpg）：第一章　題名］` など）や図版、字下げの注記を書き足す。
4. 画像を一つのフォルダにまとめ、設定ファイルを作って、EPUB を書き出す。

注記は書き出したテキストに書き足すものです。egword の原稿に書くと PDF にも印字されるので、原稿を直して書き出し直したときは、注記をもう一度書き足してください。

## テキストの書き方

青空文庫の注記と同じ書き方です。「独自」と付けたものは、このアプリで足した注記です。左の注記の一覧から入れれば、書き方を覚えていなくても入ります。

### 頁と章

| 書き方 | 意味 |
|---|---|
| 改ページ記号、または一行の `［＃改ページ］` | 改ページ。改ページごとに別のファイルになる。`［＃改丁］［＃改段］［＃改見開き］` も改ページとして扱う |
| `［＃章扉（ch01.jpg）：第一章　題名］` | 独自。画像を章扉として置き、ここから新しい章。題名は目次にだけ使い、本文には出ない。題名は省略でき、そのときは直後の見出しの題名を使う |
| `［＃章：序］` | 独自。この頁を目次に載せ、ここから新しい章。本文には何も出ない |
| `補遺／書誌` | 章扉や章の題名を「／」で区切ると、目次で階層になる（補遺の下に書誌） |
| `［＃大見出し］題［＃大見出し終わり］`、`題［＃「題」は大見出し］`、`［＃ここから大見出し］`…`［＃ここで大見出し終わり］` | 見出し。中見出し・小見出しも同じ。本文で使われているいちばん上の段階の見出しで、ファイルを分ける |
| 一行の `［＃目次］` | 独自。ここに目次を作る |
| 「目次」で始まる頁 | 手作りの目次頁。目次の項目と同じ文字の行が、自動でリンクになる |
| 一行の `［＃ページの左右中央］` | 独自。その頁を左右（縦書きでは天地）の中央に組む |

章扉の次の頁は、テキストの頭の空行の数だけ行をあけて始まります。

章の始まりが一つも見つからないと、目次には最初の頁だけが入り、警告が出ます。

### 図版

| 書き方 | 意味 |
|---|---|
| 一行の `［＃図（fig_01.jpg）入る］` | 図版。`［＃挿絵（…）入る］` も可 |
| `［＃図（fig_01.jpg）入る：説明／二行目］` | 説明付き。全角の「／」で改行 |
| 一頁にこれだけの `［＃図（cover.jpg）入る］` | 表紙（名前が cover.〜 の画像。設定 `cover_image` で変えられる） |

使える画像は JPEG・PNG・GIF・WebP・SVG です。画像が見つからないときは「［図版未着：ファイル名］」と仮に表示し、警告を出します。

### 行内の注記

| 書き方 | 意味 |
|---|---|
| `漢字《かんじ》`、`｜範囲《よみ》` | ルビ。「｜」がなければ直前の漢字の連なりに付く。漢字以外（`｜にんにく《ガーリック》`）や、漢字とかなの混じった語には「｜」が要る。「｜」のない `にんにく《ガーリック》` はルビにせず、警告を出す |
| `たしか《﹅﹅﹅》`、`｜範囲《﹅》` | 傍点 |
| `《《誌名》》` | 誌名（変換後は《誌名》）。ルビと区別するために二重にする |
| `X［＃「X」に傍点］` | 傍点。白ゴマ傍点・丸傍点・白丸傍点も |
| `X［＃「X」に傍線］` | 傍線。二重傍線・鎖線・破線・波線も |
| `X［＃「X」は太字］`、`X［＃「X」は斜体］` | 太字、斜体 |
| `12［＃「12」は縦中横］` | 縦中横 |
| `X［＃「X」は１段階小さな文字］` | 文字の大小（小さな・大きな、３段階まで） |
| `［＃太字］…［＃太字終わり］` | 範囲の形。傍点・傍線の各種・斜体・縦中横も同じ。大小は `［＃１段階小さな文字］…［＃小さな文字終わり］` |
| `※［＃「説明」、U+6318］` | 外字。U+ の符号位置があればその文字に、なければ〓にして警告 |

URL とメールアドレスは自動でリンクになります。

### 段落と範囲

| 書き方 | 意味 |
|---|---|
| 行頭の全角空白 | その数だけ字下げ |
| 行頭の `［＃２字下げ］`、`［＃天から２字下げ］` | 一行の字下げ |
| 行頭の `［＃地付き］`、行末の `［＃地付き］` | 地付き |
| 行頭の `［＃地から２字上げ］` | 地付きにして二字上げる |
| 行頭の `［＃中央揃え］` | 独自。行の中央揃え（縦書きでは天地の中央） |
| `［＃ここから２字下げ、折り返して３字下げ、地から２字上げ］`…`［＃ここで字下げ終わり］` | 範囲の字下げ。「、」で組み合わせられ、入れ子にもできる |
| `［＃ここから改行天付き、折り返して２字下げ］` | 一行目は天付き、折り返しは二字下げ |
| `［＃ここから地付き］`…`［＃ここで地付き終わり］` | 範囲の地付き。`［＃ここから地付き、地から２字上げ］` も可 |
| `［＃ここから中央揃え］`…`［＃ここで中央揃え終わり］` | 独自。範囲の中央揃え |
| `［＃ここから１段階小さな文字］`…`［＃ここで小さな文字終わり］` | 範囲の文字の大小 |
| `［＃ここから横組み］`…`［＃ここで横組み終わり］` | 独自。縦書きの本の中の横組み（原詩など） |
| 一行の `［＃区切り線］`、`［＃区切り線（破線、１０字）］` | 独自。区切り線。実線（既定）・破線・点線・二重線、長さの既定は８字 |

範囲の中の一行に `［＃地付き］` を付けると、範囲の字上げを保ったまま地付きになります。

### 脚注と文末注

本文の参照は `※1`（脚注）と `[1]`（文末注）の形で、番号は半角・全角のどちらでも構いません。注の本文は、egword が書き出すとおり、セクションの終わりに「記号＋空白＋本文」で一行ずつ並べます。注の中で改行した続きの行は、記号なしで続けます。

```
　本文の参照※1と、もう一つの参照[1]。
※1 脚注の本文。
[1] 文末注の本文。
二行目に続く。
```

- 参照は、その後に続く最初の注の並びにある、同じ番号の注に結びつきます。そのため、egword の連番の設定が「文書全体」でも「セクションごと」でも正しく結びつきます。
- 注の並びは、それ専用の頁にまとまります。
- 注の本文の前に見出し行（例「＊訳注」）を置く場合は、設定の `heading_lines` に書いておくと、変換のときに取り除かれます。
- 書式は設定で変えられます（下の `[notes]`）。

## 設定ファイル（TOML）

画面の「編集…」「新規…」で作れますが、テキストで書くと次のようになります。

```toml
writing_mode = "vertical"      # vertical（縦書き、既定）/ horizontal（横書き）
css = "book.css"               # 設定ファイルからの相対パス。省略すると同梱の標準の CSS
autolink = ["url", "mail"]     # 自動リンクの対象（url / mail / x）

[book]
title = "書名"
title_file_as = "しょめい"
identifier = "urn:uuid:0c8a…"  # 決めておくと、改訂版が同じ本として扱われる。省略すると毎回新しく作る
                               # 設定の画面の「作る」で作れる
language = "ja"
publisher = "発行者"
date = "2026-10-19"            # この形で書く
description = "説明文"

[[book.creators]]
name = "著者名"
role = "aut"                   # aut 著 / trl 訳 / edt 編 / ill 絵
file_as = "ちょしゃめい"

[notes.footnote]               # 脚注
format = "※1"                  # ※1 ＊1 注1 [1] 1] none
label = "脚注"                 # EPUB の注の欄の見出し
heading_lines = []             # テキストで注の並びの始まりを示す行（取り除く）

[notes.endnote]                # 文末注
format = "[1]"
label = "文末注"
heading_lines = []

[colophon]                     # 書くと最後に奥付の頁を作り、目次に載せる
lines = ["底本：……"]
```

脚注と文末注には、違う書式を選んでください。egword の書式のうち (1)・1)・番号だけ は、本文の箇条書きなどと区別できないので対象外です。番号の種類は算用数字だけに対応しています。

以前の原稿のための互換設定もあります。

| 項目 | 意味 |
|---|---|
| `chapter_image = 'ch(\d+)\.jpg'` | この名前の画像だけの頁を章扉とみなす（題名は「第N章」） |
| `cover_image = 'cover\.jpg'` | 表紙とみなす画像の名前（正規表現） |
| `guess_periodicals = true` | 漢字以外の直後の《…》を誌名とみなす |
| `squeeze_blank_lines = true` | 範囲注記のある本文の頁で、空行の連続を一つにまとめる |

## 既知の制限

- 縦書きの表示はビューワによって差があります。「頁の左右中央」は Kindle・Kinoppy では正しく表示されますが、海外製のビューワでは崩れることがあります。
- 字上げは余白（margin）で付けています。余白を無視するビューワでは、地付きと同じ位置に表示されます。
- egword の脚注の「ページごとに連番を振り直す」には対応していません（EPUB には紙の頁がないため）。
- 外字注記は U+ の符号位置が書かれたものだけを文字にします。JIS の面区点番号だけのものは〓になります。
- 改丁・改段・改見開きは、どれも改ページとして扱います。
- EPUB の検査（EPUBCheck）は含んでいません。ストアに出すときなどは、別に [EPUBCheck](https://www.w3.org/publishing/epubcheck/) で確かめてください。

## 開発

| 場所 | 中身 |
|---|---|
| `core/` | 変換の本体とテスト |
| `cli/` | コマンド |
| `wasm/` | 変換の本体を WebAssembly にして画面から使えるようにするもの |
| `app/` | 画面（TypeScript・CodeMirror）。`app/dist/` が組み立て済みのもので、ブラウザ版としてそのまま公開している |
| `desktop/` | デスクトップ版（Tauri）。ファイルの読み書きと選ぶ窓だけを受け持つ |
| `mac/` | Mac のアプリの Info.plist |

テスト：

```
./run_tests.sh
```

このアプリは、作者が手元で使っていた Python 版を移したものです。テストでは、Python 版で変換した 75 例と設定の窓の 42 例（`tools/` のスクリプトで記録したもの）をやり直し、XHTML・目次・OPF・警告・zip の中身まで同じになるかを確かめます。

画面を作り直すとき（`app/src/` や `wasm/`・`core/` を変えたとき）は、Node.js と、Rust の WebAssembly の組み立て（`rustup target add wasm32-unknown-unknown` と `cargo install wasm-bindgen-cli --version 0.2.100`）が要ります。

```
./build_wasm.sh
cd app && npm install && node build.mjs
```

`app/dist/` を作り直してから GitHub に上げると、ブラウザ版も新しくなります。使い方の動画の撮り直し方は `tools/guide/README.md` にあります。
